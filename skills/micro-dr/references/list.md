# list

Read the project's type files, using the headings as the index; add `archive.md` or `global/` when asked. Filter by any of: free text in the entries, status, type, tag, path in `applies-to`, date (`decided`, else the id's date), branch in `recorded`, undistilled (accepted without `distilled`).

Sort by the id's date, newest first. One line each: id, the decision in one sentence, status. State the count of the filtered list.

For an export, write the matching entries in full, oldest first, to a file the user names outside the repo.

Done when the list or export is delivered.
